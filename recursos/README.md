# Recursos locais

Esta pasta fica **fora do Git** (exceto este README).

Use-a para materiais pessoais de estudo que você **não** tem direito de redistribuir, por exemplo:

- PDFs de terceiros
- dumps de simulados pagos
- anotações com conteúdo proprietário

O repositório público deve conter apenas material original ou com licença clara de compartilhamento.
